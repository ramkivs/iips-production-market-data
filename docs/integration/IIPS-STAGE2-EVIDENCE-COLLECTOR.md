# Stage 2 non-production evidence collector

This is an IPD-owned collection utility, not an IRR change or W20 acceptance. It was derived from IPD main `0b6a0bea173034e0822ddcda36cd176111a0a77a` and IRR main `c9115f3280d70eb66bf9d59275aeade572cb04a7`. Check for contract drift before use. Run only on the authorized **non-production** Windows host, under the operating user's existing access controls. Do not run with a production endpoint or copy personal data into a repository. It never starts, stops or configures a service, never runs migrations, calls no quote/refresh/write endpoint, does not echo tokens or raw responses, and does not open the portfolio database directly.

## Run

PowerShell 7.2+ and Node.js 22.13+ (with `node:sqlite`) are required. Use an IPD checkout containing this script and `scripts/stage2/readonly-reports.cjs`. Existing IRR and IPD services must already be running on the local machine. Set the environment in the **current shell** using the host's existing authorized configuration, not values pasted into a shared transcript. `IIPS_G2_IPC_ENDPOINT` is the existing IPD named pipe; `IIPS_DATA_DIR` is the existing IRR data domain; optional `IIPS_NP04_DATABASE_PATH` and `IIPS_REPORTS_OWNER_PATH` identify the existing Reports database and owner carrier. The market token is read only from `IIPS_MARKET_DATA_TRANSPORT_TOKEN`. Do not print it. Pass actual locally configured port numbers (ports are required operator inputs, not assumed defaults):

```powershell
# Set these two variables to the already-running local service port numbers.
$irrPort = [int](Read-Host 'IRR local HTTP port')
$marketPort = [int](Read-Host 'IPD market-data local HTTP port (0 if unavailable)')
$output = Join-Path $env:TEMP ("iips-stage2-" + [guid]::NewGuid().ToString('N') + '.json')
.\scripts\Collect-IipsStage2Evidence.ps1 -IrrPort $irrPort -MarketPort $marketPort -OutputFile $output -ConfirmNonProduction
Write-Host "Evidence file: $output"
```

The result is one new UTF-8 JSON file under `%TEMP%`; choose and retain its actual filename securely (the command uses a GUID to prevent collisions). An existing output file is never overwritten. Optional `-FinancialRightsDocument` and `-MarketRightsDocument` accept absolute paths to already-existing local supporting documents: only their SHA-256 digests, not paths or contents, are output. Hashing is not verification or permission. The operator must review the output before sharing; small counts, timestamps, and hashes may themselves be sensitive. Raw identifiers, symbols, values, paths, provider text, rights notes, tokens and error messages are excluded. Anonymous row numbers are per-run only, not stable identities.

All observations have collection start/end times; individual freshness timestamps have their own clocks. Manifest `dataAsOf`, `knownAsOf`, `lastImportAt` are distinct from financial period and filing dates. Declared dataset counts do not establish same-revision portfolio coverage. Identity and market output may be partial; incomplete and missing fields remain UNKNOWN. No eligibility denominator, coverage percentage, monetary coverage, or source-rights approval is fabricated.

## W05/W06 source-rights dossier

For each selected source, retain securely: source provider and source/product, dataset or feed/version and digest, source document/terms identifier and version/date, rightsholder and granting party, the applicable subject/account or scope, territory, use and purpose (including personal/non-production), acquisition/access, processing/derived outputs, display, retention and deletion, onward sharing/redistribution restrictions, effective/expiry dates, any conditions/limitations, review date, and precise supporting-document reference/digest. Track an explicit UNKNOWN when any item is absent. For financials also retain filing/document provenance, issuer, filing date, period start/end, annual/quarterly form, statement scope, basis and restatement/normalization lineage. For market data retain feed/instrument/exchange, source and observation time, receipt and evaluation times, and applicable quote/redistribution/retention terms. Do not publish sensitive agreement contents or credentials in the evidence package.

IRR manifest `sourceRights.state` is `SYNTHETIC`, `OPERATOR_ASSERTED` (nonempty `basis`), or `UNKNOWN`. An operator assertion plus its basis is **not** independent proof of third-party permission. Provider/licence labels are not permission. Where third-party rights apply, independently inspect applicable terms or a named agreement/permission from the rightsholder and record the scope, dates, and document digest; unknown is neither approval nor proof of denial. The market freshness API does not declare rights. B03 remains open until the applicable rights are evidenced.

## Reproducible synthetic tests

`node --test tests/stage2/readonly-reports.test.cjs` exercises only temporary synthetic data and verifies owner filtering, unchanged DB bytes, invalid carrier and WAL refusal. On Windows with PowerShell 7 and Node 22, `./tests/stage2/collector-windows.test.ps1` runs a local synthetic named-pipe and loopback HTTP fixture, checks aggregation and secret exclusion, and checks refusal to overwrite output. The GitHub Windows workflow runs both. No actual data or credentials are needed.
