# Dhan quote retries, cancellation and portfolio batching

The owner reversed the W-12 single-attempt product restriction. The local candidate uses `IIPS_DHAN_QUOTE_MAX_ATTEMPTS` (integer 1–10, default 3 total attempts). Transient transport failures, timeouts, 429 and HTTP 500/502/503/504 are retried with exponential backoff and jitter; permanent failures stop. Exhaustion is explicit. Valid Retry-After on 429/503 is honored; a delay over 30 seconds returns the failure rather than retrying early. Quote attempts, including batches and retries, use the same process-local serialized pacing gate (one second after the preceding fetch completes) and rate budget. A bounded, sanitized in-memory service diagnostics accessor reports attempts and cancellation without credentials, raw headers, bodies or identity.

The authenticated `POST /v1/quotes/batch` accepts `{ "instruments": [{ "companyId": "...", "securityId": "ISIN:...:EQ", "exchangeSegment": "NSE_EQ" }] }`. Its response has ordered per-item canonical `results`, including independent failures. The service also offers `getPortfolioQuotes`; the transport client provides a batch method. Exact identity and mapping are checked before egress. A provider batch is limited to 1000 instruments; requests over that are split. The local endpoint/service accepts at most 2000 items, with a 256 KiB HTTP body cap. The provider limit is documented in [Dhan's v2 release notes](https://dhanhq.co/docs/v2/releases/) and its [market quote documentation](https://dhanhq.co/docs/v2/market-quote/). Duplicate simultaneous identically ordered batches share work; this is not cross-process coordination. Partial/missing/malformed items do not invalidate unrelated valid items. Each successful item uses the existing canonical normalizer and retains observation timestamps, quality and lineage. The bounded default quote cache and status history hold 512 entries.

For quotes, the local HTTP deadline (default 10 seconds) or client disconnect aborts the caller's operation, including queued work, backoff and the HTTPS fetch. Coalesced work continues only while another caller still needs it. A provider may already have processed a request before the abort; a timeout is not proof of non-receipt. Injected custom transports must honor the supplied AbortSignal. An already-running credential lookup is not itself interruptible, but cancellation is checked again before any provider send. The unrelated historical endpoint retains its pre-existing timeout behavior. Long Retry-After values and multiple slow attempts may exceed the local HTTP deadline; no retry continues for an abandoned quote. Diagnostics are in memory, not an HTTP route or persisted.
