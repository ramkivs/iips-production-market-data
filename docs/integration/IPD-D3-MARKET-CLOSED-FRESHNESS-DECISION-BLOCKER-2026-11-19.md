## 4. Deterministic five-trading-day method and examples

**Decision proposal for owner endorsement, not implemented:** given qualified observation date D, exchange E, evaluation cutoff T and pinned evidence versions, let C(E,T) be the set of verified completed live equity trading dates by T. Then `age = count(d in C(E,T) where D < d)`. Exclude D; count distinct dates once. The established threshold is five. Proposed boundary expression is `age <= 5` within allowance and `age > 5` beyond allowance; record explicit endorsement of that inclusive comparison, without changing the threshold. Missing price, unresolved mapping, future/non-trading observation date, incomplete calendar coverage or uncertain completion yields UNKNOWN with reason, not a guessed count or freshness approval.

Use a daily evaluation snapshot with an explicit latest-completed-trading-date watermark, qualified independently of whether the selected stock has a new row. An in-progress date does not count yet; once it is verified completed it counts even if the latest stock price is still Friday's. No intraday polling or auction-window monitoring is required. If today's completion cannot be established, report an as-of prior-day result explicitly or UNKNOWN for the requested current cutoff; never silently declare today's session closed or extend the allowance because a report is late. The owner must approve that daily snapshot/completion-evidence convention.
